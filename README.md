# divyakush.is-a.dev

A GitHub Pages site that permanently redirects [divyakush.is-a.dev](https://divyakush.is-a.dev) to my portfolio at [www.divyakush.com](https://www.divyakush.com).

The subdomain is registered through [is-a.dev](https://is-a.dev). Every path lands on the portfolio:

| File | Purpose |
| --- | --- |
| `index.html` | Redirect with a canonical link, meta refresh and a script fallback |
| `404.html` | Same redirect for any unknown path |
| `CNAME` | Binds the Pages site to `divyakush.is-a.dev` |
| `google*.html` | Google Search Console ownership verification |
